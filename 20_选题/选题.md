# 选题

> 维护规则：
> 同类型选题追加到对应表格末尾。
> 出现新的内容类型时，在文末新增一个二级标题（`# xxx`）和对应的同结构表格。
> 列固定为：是否使用 / 选题 / 切入角度。
> 是否使用：默认为空，手动填。`0` = 待写，`1` = 已使用（已写成文章）。

# 好习惯

| 是否使用 | 选题                        | 切入角度                                                    |
| ---- | ------------------------- | ------------------------------------------------------- |
| 1    | 坚持早起 30 天，我才明白的 5 件事      | 原来拉开差距的不是"起得早"，是早起后那段没人打扰的、属于自己的决策时间——你不是在跟别人比，是在跟自己抢时间 |
| 1    | 读了 50 本书，真正改变我的只有这 7 句话   | 不是读得多有用，是你读进去那 1 句、并且真的用起来了——一年读 50 本不如 1 本里有 1 条被践行    |
| 1    | 坚持复盘 100 天，我才发现大多数人都复错了   | 复盘不是批斗大会，是实验室记录——只盯错误不记成功，越写越否定自己                       |
|      | 戒掉这 5 个睡前习惯，我终于不失眠了       | 不是手机的问题，是你睡前做的那几件事，大脑根本停不下来——把入睡前最后一小时从算法手里夺回来          |
|      | 坚持喝水 30 天，身体和情绪的真实变化      | 别纠结八杯水，真正有效的是"用一杯水作为每件正事的开场仪式"——它顺便解决了久坐和分心             |
|      | 每天散步 30 分钟，一个月后身体的变化      | 不是为了减肥，是给大脑一段"不被信息轰炸"的时间——你会发现家旁边那条路，你走了三年都没注意过拐角       |
|      | 吃饭时把手机倒扣，坚持一个月我的变化        | 不是自律，是发现认真吃完一碗饭，情绪就能缓过来一半——你不是在吃饭，是在让算法替你"陪饭"           |
| 1    | 每天写 3 行字，坚持了 100 天的真实感受   | 不是写日记，是给情绪一个"今天就到这里"的句号——3 行就够，写多了反而变成另一个 KPI           |
|      | 把手机调成灰度模式一周，发生了这些变化       | 不是戒手机，是发现原来手机没那么好玩了——你戒不掉的不是手机，是红点点和高饱和图标的奖励机制          |
| 1    | 每周留一个晚上什么都不安排，我的变化        | 你缺的不是娱乐，是"没有下一件事在等"的松弛——一周里总得有一个晚上，明天的事不归今晚管            |
|      | 早上先拉开窗帘再碰手机，一周后的变化        | 你睁眼第一件事不是"醒来"，是"接收别人的消息"——先让自然光进来，再让信息进来，一天才是从你自己开始的    |
|      | 我试了"待办清单只写 3 件事"，效率反而更高了  | 列 10 件不是有规划，是给自己留了 7 件可以"理直气壮没做完"的事——3 件做完，一天就不算亏       |
|      | 出门前把明天要穿的衣服摆好，早上少一半烦躁     | 早晨最消耗意志力的不是通勤，是"今天穿什么"那 10 分钟的犹豫——前一晚花 30 秒摆好，第二天少纠结    |
|      | 每周日晚上花 10 分钟整理一次包，心就不乱了   | 包里面永远有"上次忘了拿出来"的小票、耳机、薄荷糖——包乱，心就乱，10 分钟就能清空             |
|      | 坐电梯走一层楼梯，一个月后的变化          | 不是为了锻炼，是给自己一个"今天我主动做了一件小事"的开头——意志力是被这种小选择撑起来的           |
|      | 收到消息不秒回，坚持一周的社交变化         | 不是高冷，是你终于不用"随时在线"了——留 30 秒，你会发现一半的消息根本不急着回              |
|      | 每天晚上把第二天要带的东西放在门口         | 你早上忘带伞、忘带钥匙，不是记性差，是大脑在"赶时间"模式里根本不记得——放在门口，眼睛会替你记        |
|      | 喝咖啡之前先喝一杯温水，一周后的变化        | 你以为你需要咖啡，其实你只是脱水了——早上那杯咖啡压下去的困意，有一半是身体在喊"我要水"           |
|      | 把大任务拆成"坐下来 5 分钟就能开始"的小动作  | 你拖延不是因为懒，是任务在你脑子里太大——"写报告"会让人瘫，"打开文档写第一行字"人人都能做         |
|      | 每工作一小时站起来看远处 30 秒，效率翻倍    | 不是为了护眼，是让大脑从"深度专注"里出来喘口气——30 秒后再坐回去，效率比硬扛两小时高得多         |
|      | 把手机放在离床一米远的地方充电，一周后       | 你起床关闹钟必须下床，顺便就醒了——别让手机成为你醒来第一件碰的东西                      |
|      | 每天写一件"今天做得还不错的小事"，情绪变了    | 不是写日记，不是复盘错误，是给自己记功——你太久没夸过自己了                          |
|      | 吃饭时每口多嚼十下，别边看手机边扒         | 你不是在吃饭，是在给胃"倒垃圾"——慢下来，胃会感谢你                             |
|      | 坐下来工作前先把桌面收拾到能看见桌面        | 乱桌面是注意力的天敌——你以为你在找东西，其实你的大脑一直在"处理"视觉噪音                  |
|      | 每天下班前 5 分钟列好明天第一件事，再也不内耗  | 第二天来了直接开干，不用花半小时想"我今天该干嘛"——启动成本才是最大的时间小偷                |
|      | 把闹钟提前 10 分钟，整个早上都不慌了      | 不是多睡，是不用"抢时间"了——不慌不忙地洗脸、喝水、出门，比多睡 10 分钟管用               |
|      | 每周固定一天不看短视频，这是我的感受        | 不是戒手机，是让大脑重新学会"无聊"——你已经太久没跟自己待着了                        |
|      | 喝水的时候站着喝，顺便拉伸一下           | 一杯水的时间，也是身体的休息——你一天坐太久了，站起来那 30 秒比你想象的重要                |
|      | 遇到不想做的事告诉自己"先做 5 分钟"，拖延好了 | 5 分钟后你往往会继续——拖延不是因为懒，是"开始"太难了                           |
|      | 睡前把手机放到另一个房间充电，一周后        | 卧室只用来睡觉，不用来刷手机——不看手机的那半小时，才是你真正的休息                      |

# 人生感悟

| 是否使用 | 选题                     | 切入角度                                                |
| ---- | ---------------------- | --------------------------------------------------- |
| 1    | 人到中年，朋友越来越少            | 朋友变少不是失败，是人生开始做"减法"后的自然结果——留下来的那 2-3 个，才是真正的"社交资产"  |
| 1    | 你那么懂事，一定很累吧            | "懂事"的本质是从小练就的情绪察言观色技能，它保护过童年的你，但正在消耗成年的你            |
| 1    | 为什么越长大越不想解释            | 不是不想解释，是终于发现"被误解"其实是一件成本极低的事——比起解释，把时间留给结果更划算       |
| 1    | 那些你以为过不去的坎，后来呢         | 时间没有治愈你，是你在那些坎上长出了新的骨头——回头看时，坎还在，只是你已经比它高了          |
| 1    | 人这一辈子，到底在追求什么          | 大多数人追求的不是"意义"，而是"不被别人的节奏推着走"的那份从容——意义感是副产品，不是目标     |
|      | 原来"普通"才是大多数人拼命才够到的生活   | 我们年轻时都以为自己会不一样，后来才发现——能把普通的日子过得不糟，已经是很多人拼尽全力的结果     |
| 1    | 三十岁以后，我不再急着反驳别人        | 不是变圆滑了，是终于明白：你说服不了一个跟你经验完全不同的人——反驳只是在浪费自己的情绪        |
|      | 有些路，只能一个人走，不是因为孤独      | 是因为你走到那个位置了，身边的人都没法陪你走那一段——孤独不是惩罚，是成长的门票            |
|      | 我们终于活成了当年最讨厌的那种人吗      | 不是活成了讨厌的人，是终于看清了当年讨厌的那些人——他们也有自己的难处，你只是到了他们的位置才懂    |
|      | 人生最大的遗憾，是"我本可以"        | 真正让人后悔的不是"做错了"，是"我本可以做，却没敢"——做错了可以改，没做会想一辈子         |
|      | 长大的标志，是不再向任何人诉苦        | 不是变坚强了，是终于发现：说了也没人真的懂，而且第二天还要面对——诉苦是奢侈品，不是必需品       |
|      | 你不是真的喜欢独处，是终于懒得勉强了     | 一个人待着确实舒服，但更深的原因是——你终于承认，那些让你勉强自己的社交，其实没那么重要        |
|      | 时间把人分成了两拨：一拨在做梦，一拨在过日子 | 不是谁对谁错，是有些人还在等"以后"，有些人已经开始"现在"了——十年后你们再见面，话都对不上     |
|      | 有些再见，是没说出口的            | 真正的告别没有仪式，就是某一天那个人从你生活里消失了，你也没主动找——大家都默认了，就这样吧      |
|      | 人到一定年纪，才明白"平安"两个字多重    | 年轻时觉得"平安"太普通，现在才知道——家人平安、身体没大病、晚上睡得着，已经是顶级的幸福       |
|      | 你羡慕的那种生活，别人也在羡慕你       | 你以为别人都过得比你好，其实每个人都在自己的日子里咬着牙——你看到的是别人的高光，别人看你也一样    |
|      | 原来成长不是得到，是终于敢放弃        | 小时候以为成长是"拥有更多"，后来才发现是"敢不要了"——敢放弃那个不适合你的工作、那段关系、那个标签 |
|      | 那些年你以为的"丢人"，后来根本没人记得   | 你以为所有人都在看你笑话，其实大家都在忙着担心自己的事——你出的糗，第三天就没人记得了         |
|      | 中年以后，快乐变简单了，也变难了       | 简单是因为——一顿好饭、一个好觉、没人打扰的下午，就够了；难是因为——这些小事，经常被工作和家庭挤没  |
|      | 一辈子那么长，怕的不是走错，是一直不敢走   | 走错了可以调头，怕的是你站在原地纠结十年，最后回头一看——最好的那几年，都用来犹豫了          |
|      | 原来"放过自己"才是这辈子最难的功课     | 你对别人都宽容，唯独对自己下狠手——做错一件事就骂自己半年，其实别人早就忘了              |
|      | 有些人出现在你生命里，就是为了教你说"不"  | 那些让你不舒服的人，不是来害你的，是来逼你长出边界的——感谢他们，然后远离               |
|      | 年纪越大，越喜欢"确定"的东西        | 不是变保守了，是折腾不起了——一顿确定的饭、一个确定的人、一份确定的工资，比什么都让人安心       |
|      | 你不需要向所有人证明你过得好         | 朋友圈晒的、饭局上说的，都是你想让别人看到的——真正的日子好不好，你自己知道就行            |
|      | 那些年你拼命想逃开的家，后来成了最想回的地方 | 年轻时恨不得越远越好，现在才懂——那个骂你骂得最狠的人，也是你生病时第一个给你煮粥的人         |
|      | 人生没有白走的路，但有些弯路真的可以不走   | 不是所有经历都值得感谢——有些坑是可以提前避开的，别把"吃亏"美化成"成长"              |
|      | 真正的成熟，是学会对自己的选择负责      | 选了就认，别后悔，别抱怨——你选的工作、选的人、选的生活，都是你自己一步一步走出来的          |
|      | 那些年你羡慕的别人的生活，也有你看不到的难  | 她看起来嫁得好，其实在家受气；他看起来赚得多，其实天天加班到凌晨——你羡慕的是结果，不是过程      |
|      | 有些道理，不是听懂了才算，是经历过才算    | 别人跟你说一百遍"别熬夜"，不如你自己病倒一次——道理是别人的，教训才是自己的             |
|      | 一辈子很短，别跟不值得的人和事较劲      | 你为一个人难过三个月、为一件事纠结半年——回头看，那个人那件事，根本不配占你那么久           |

# 生活感悟

| 是否使用 | 选题 | 切入角度 |
| --- | --- | --- |
|  | 房子是租来的，但生活不是 | 真正的"生活感"不靠钱堆，而是那几件无论搬到哪都要带上的小东西——它们定义了"你的生活"长什么样 |
|  | 一个人吃饭，会不会很可怜 | 一个人吃饭的质量，藏着你对自己的重视程度——不是矫情，是你愿不愿意为自己花 20 分钟 |
|  | 断舍离，到底在断什么 | 扔的不是东西，是"以后可能会用到"的那个焦虑的自己——每留一件旧物，都是在给过去交税 |
| 1 | 周末留半天，给自己充会电吧 | 真正的休息不是"安排满"，而是允许自己无所事事一个下午——大脑需要的是"留白"，不是另一个 KPI |
|  | 为什么越忙的人越要好好做饭 | 做饭是成年人为数不多的"确定性掌控感"——世界再乱，这道菜咸了淡了，结果立刻可见 |
|  | 和老朋友见面，聊得最多的已经不是梦想 | 不是没话聊，是大家都在刻意避开"当年那个想做梦的自己"——聊孩子聊工作是安全的，聊梦想会暴露这几年过得怎么样 |
|  | 开始自己买菜以后，才懂一顿家常饭的分量 | 你不是学会了做饭，是终于知道"一顿饭从买菜到端上桌"要花多少心思——妈妈做了二十年，你以前连谢都没说过 |
|  | 旅行里记得最清楚的，常常是计划之外的半天 | 记住的不是"打卡了哪"，是那半天里你没有目的地、没有目标、只是走着——那才是旅行真正开始的瞬间 |
|  | 跑步跑得很慢，也能看见平时错过的风景 | 慢跑不是为了练体力，是给你一段"眼睛终于肯从手机抬起来"的时间——你会发现家旁边那条路，你走了三年都没注意过拐角那家花店 |
|  | 重回住过的地方，有些熟悉只留在记忆里 | 变的不是那个地方，是你——记忆里的那条路是你十几岁时的腿量出来的，现在你用成年人的脚步走，当然觉得小、觉得近 |
|  | 开始留意父母的白发以后，回家有了不同的心情 | 真正难受的不是看见白发，是你突然意识到——你已经长大到，要开始用当年他们看你的眼神，去看他们了 |
|  | 超市推车推到生鲜区，才知道自己今天想吃什么 | 你不是在买菜，是在给自己安排一周的"盼头"——周末炖一锅汤，工作日晚上炒个青菜，日子就是这么一口一口熬过来的 |
|  | 下雨天窝在家里，比出去玩更治愈 | 不是懒，是终于不用"必须出门"了——外面下雨，你在家的每一分钟都是理直气壮的，连内疚都没有 |
|  | 阳台上那盆快死的绿植，被我救活了 | 养植物最神奇的不是它活了，是你开始每天早上第一件事去看它——你有了一个比你更需要被照顾的小东西 |
|  | 搬进新家第一年，我先买了一双好看的拖鞋 | 家不是从买家具开始的，是从"我一进门就想脱鞋"开始的——那双拖鞋决定了你对这个房子的第一印象 |
|  | 菜场里那些会跟你多聊两句的摊主，是生活的底气 | 他记得你爱买瘦的还是肥的，会多给你塞一根葱——这种"被记住"的感觉，是你在写字楼里永远得不到的 |
|  | 深夜便利店的灯，照过很多不想回家的人 | 你不是饿了，是需要一个"不被问"的地方——站在货架前面挑酸奶的那两分钟，是成年人一天里唯一属于自己的时间 |
|  | 把冬天的厚被子晒过以后，睡觉像被太阳抱住 | 阳光是有味道的，那种味道是"今天什么都不用想"的味道——你钻进被子的那一刻，所有烦恼都被晒在外面了 |
|  | 那些一个人住的周末，把日子过成了自己的样子 | 不用迁就谁的口味、不用考虑谁的作息——你想几点起就几点起，想吃泡面就吃泡面，这才是生活本来的样子 |
|  | 收拾抽屉时翻出十年前的电影票根 | 你不是在翻旧物，是在翻当年那个还会为一场电影开心的自己——票根上的名字已经模糊了，但那天晚上的风你还记得 |
|  | 阳台上种点葱，比养花都治愈 | 花是给别人看的，葱是给自己用的——每天早上掐两根，下面条的时候，你会觉得自己在认真生活 |
|  | 周末早上不用定闹钟自然醒，是顶级奢侈 | 不是睡懒觉，是醒来不用想"今天要干嘛"——那种没有目的的早晨，才是真正的休息 |
|  | 把家里的灯换成暖光，整个屋子都温柔了 | 白光让人想干活，暖光让人想回家——你下班回家那盏灯的颜色，决定了你进门那口气松不松 |
|  | 自己煮一锅火锅，比去火锅店更爽 | 不用抢肉、不用看别人吃完了没、不用凑时间——你想煮到几点就煮到几点，这才是火锅的本质 |
|  | 下雨天听到窗外的雨声，莫名安心 | 不是矫情，是雨声把世界隔在了外面——你在屋里，哪也不用去，这一天就是理直气壮的 |

# 情绪疗愈

| 是否使用 | 选题 | 切入角度 |
| --- | --- | --- |
|  | 有些委屈，当时笑着带过，回家才觉得难受 | 你的情绪不是"当时没产生"，是被你当场按了暂停——它没消失，只是等你一个人回到家、关上门，才一次性结账 |
|  | 明明很累，休息的时候却总觉得自己在偷懒 | 你不是在休息，你是在"边休息边审判自己"——大脑一半在躺，一半在骂，比上班还累 |

|  | 突然不想说话，不想见人，不是病了 | 就是"社交电量"耗尽了——你需要一个人待着，谁也别找你，这不是孤僻，是充电 |

|  | 那些让你睡不着的事，其实没那么大 | 你翻来覆去想了一晚上，第二天跟朋友一说，她笑了："就这？"——你把它放大了十倍 |
|  | 允许自己偶尔"没用"一天 | 不是每天都要有产出、有进步、有意义——你可以躺着、发呆、看剧，这一天不算白过 |
|  | 你不是一个人在扛，只是你以为没人看见 | 你以为你不说，别人就不知道——其实大家都在默默扛着，只是没人先开口 |
|  | 心情不好的时候，先去睡一觉 | 不是逃避，是你的身体在报警——睡一觉起来，那件事好像也没那么大了，很多答案都是睡醒了才有的 |

# 婚姻两性

| 是否使用 | 选题 | 切入角度 |
| --- | --- | --- |
|  | "你告诉我，我就做"：为什么这句话反而让伴侣更累？ | "你说"翻译过来是"我不想负责，也不想动脑筋——如果搞砸了，是你选的"——这不是温柔，是把决策成本全推给了你 |
