# 选题

> 维护规则：
> 同类型选题追加到对应表格末尾。
> 出现新的内容类型时，在文末新增一个二级标题（`# xxx`）和对应的同结构表格。
> 列固定为：是否使用 / 选题 / 核心问题 / 常见解释 / 切入角度。
> 是否使用：默认为空，手动填。`0` = 待写，`1` = 已使用（已写成文章）。

# 好习惯

| 是否使用 | 选题                  | 核心问题          | 常见解释                      | 切入角度                                                          |
| ---- | ------------------- | ------------- | ------------------------- | ------------------------------------------------------------- |
| 1    | 早起 1 小时，到底改变了什么     | 早起真的能逆袭人生吗    | 早起自律 = 优秀，多出来的时间用来学习 / 健身 | 真正拉开差距的不是"起得早"，而是早起后那段不被消息打断的、属于自己的决策时间                       |
| 1    | 每天读 30 分钟书，为什么没用    | 读书改变命运是鸡汤吗    | 读书要坚持、要做笔记、要输出            | 问题不在"读多少"，而在读的是"信息"还是"能改变行为的那一句话"——一年读 50 本不如 1 本里有 1 条被真正用起来 |
| 1    | 坚持复盘，为什么越复越焦虑       | 复盘是不是一种自我 PUA | 复盘要写得详细、要找问题、要定改进计划       | 大多数人的复盘是"批斗大会"而非"实验室记录"——只盯错误不记成功，越写越否定自己                     |
|      | 睡前不刷手机，真的能变好吗       | 戒手机是不是太反人性    | 刷手机伤眼、失眠、皮肤差              | 真正的收益不是睡眠，而是把"入睡前最后一小时"从被算法投喂，交回给自己——这是一天中唯一能自己写结尾的时间         |
|      | 坚持喝水，一年后身体会怎样       | 八杯水是不是玄学      | 喝水排毒、皮肤好、代谢高              | 别纠结毫升数，真正有效的是"用一杯水作为一天中每件正事的开场仪式"——它顺便解决了久坐和分心                |
|      | 每天散步 30 分钟，比办健身卡更养人 | 为什么办了卡还是不去    | 要运动、要出汗、要坚持、要请私教          | 真正改变你的不是强度，是"无目的、不被打断的身体移动"——它把你从"被任务推着走"切回"我在走"              |
|      | 吃饭时把手机倒扣，一个月后会怎样    | 吃饭刷手机真的只是习惯吗  | 下饭、不浪费时间、一个人吃饭尴尬          | 你不是在吃饭，是在让算法替你"陪饭"——一个月后你会发现，原来认真吃完一碗饭，情绪就能缓过来一半              |
| 1    | 每天写 3 行字，比写日记更治愈    | 写日记为什么坚持不下来   | 要写得有内容、要复盘、要坚持            | 日记的作用不是"记录生活"，而是给情绪一个"今天就到这里"的句号——3 行就够，写多了反而变成另一个 KPI        |
|      | 把手机调成灰度模式一周，会发生什么   | 戒不掉手机是意志力问题吗  | 要自律、要卸 App、要定屏锁时间         | 你戒不掉的不是手机，是那些红点点和高饱和图标的"奖励机制"——把它变灰，诱惑会消失一大半                  |
| 1    | 每周留一个晚上"什么都不安排"     | 周末为什么越休息越累    | 要出去玩、要社交、要补课、要出门透气        | 你缺的不是娱乐，是"没有下一件事在等"的那种松弛——一周里总得有一个晚上，明天的事不归今晚管                |

| 1    | 你那么懂事，一定很累吧    | 懂事是优点还是陷阱  | 懂事的人招人喜欢、情商高      | "懂事"的本质是从小练就的情绪察言观色技能，它保护过童年的你，但正在消耗成年的你           |
| 1    | 为什么越长大越不想解释    | 沉默是成熟还是冷漠  | 懂你的人不必解释、不懂的解释也没用 | 不是不想解释，是终于发现"被误解"其实是一件成本极低的事——比起解释，把时间留给结果更划算      |
| 1    | 那些你以为过不去的坎，后来呢 | 时间真的能治愈一切吗 | 时间会冲淡一切、向前看就好     | 时间没有治愈你，是你在那些坎上长出了新的骨头——回头看时，坎还在，只是你已经比它高了         |
| 1    | 人这一辈子，到底在追求什么  | 意义感到底从哪来   | 追求财富、自由、幸福        | 大多数人追求的不是"意义"，而是"不被别人的节奏推着走"的那份从容——意义感是副产品，不是目标    |

# 生活感悟

| 是否使用 | 选题 | 核心问题 | 常见解释 | 切入角度 |
| --- | --- | --- | --- | --- |
|  | 房子是租来的，但生活不是 | 租房也要精致吗 | 要买好家具、要布置、要仪式感 | 真正的"生活感"不靠钱堆，而是那几件无论搬到哪都要带上的小东西——它们定义了"你的生活"长什么样 |
|  | 一个人吃饭，会不会很可怜 | 独居是不是孤独 | 一个人也要好好吃饭、点外卖凑合也行 | 一个人吃饭的质量，藏着你对自己的重视程度——不是矫情，是你愿不愿意为自己花 20 分钟 |
|  | 断舍离，到底在断什么 | 扔东西是不是太浪费 | 物品少 = 清爽 = 自由 | 扔的不是东西，是"以后可能会用到"的那个焦虑的自己——每留一件旧物，都是在给过去交税 |
| 1 | 周末留半天，给自己充会电吧 | 休息是不是也要有意义 | 要学习、要运动、要出门社交 | 真正的休息不是"安排满"，而是允许自己无所事事一个下午——大脑需要的是"留白"，不是另一个 KPI |
|  | 为什么越忙的人越要好好做饭 | 做饭是不是浪费时间 | 做饭解压、健康、省钱 | 做饭是成年人为数不多的"确定性掌控感"——世界再乱，这道菜咸了淡了，结果立刻可见 |
|  | 和老朋友见面，聊得最多的已经不是梦想 | 为什么越长大朋友见面越没话聊 | 大家变了、圈子不同了、没有共同话题 | 不是没话聊，是大家都在刻意避开"当年那个想做梦的自己"——聊孩子聊工作是安全的，聊梦想会暴露这几年过得怎么样 |
|  | 开始自己买菜以后，才懂一顿家常饭的分量 | 为什么自己做饭后对妈妈做的饭不一样了 | 自己做饭健康、省钱、比外卖好吃 | 你不是学会了做饭，是终于知道"一顿饭从买菜到端上桌"要花多少心思——妈妈做了二十年，你以前连谢都没说过 |
|  | 旅行里记得最清楚的，常常是计划之外的半天 | 为什么做了攻略的旅行反而记不住 | 计划太满、节奏太快、要放松不要赶 | 记住的不是"打卡了哪"，是那半天里你没有目的地、没有目标、只是走着——那才是旅行真正开始的瞬间 |
|  | 跑步跑得很慢，也能看见平时错过的风景 | 跑步快和慢，差别到底在哪 | 跑得快燃脂、跑得慢没用、要配速要心率 | 慢跑不是为了练体力，是给你一段"眼睛终于肯从手机抬起来"的时间——你会发现家旁边那条路，你走了三年都没注意过拐角那家花店 |
|  | 重回住过的地方，有些熟悉只留在记忆里 | 为什么老地方回去总会失望 | 地方变了、装修拆了、物是人非 | 变的不是那个地方，是你——记忆里的那条路是你十几岁时的腿量出来的，现在你用成年人的脚步走，当然觉得小、觉得近 |
|  | 开始留意父母的白发以后，回家有了不同的心情 | 父母变老是什么时候发现的 | 突然有一天发现他们老了、要多陪伴、要孝顺 | 真正难受的不是看见白发，是你突然意识到——你已经长大到，要开始用当年他们看你的眼神，去看他们了 |

# 职场

| 是否使用 | 选题 | 核心问题 | 常见解释 | 切入角度 |
| --- | --- | --- | --- | --- |
|  | 为什么你很努力，却总不被看见 | 职场到底看什么 | 要加班、要多干活、要听话 | 被看见的关键不是"做得多"，而是"让关键的人知道哪件事是你做成的"——功劳不会自动浮现 |
|  | 离职裸辞，到底需要多少勇气 | 裸辞是冲动还是清醒 | 要攒够 6 个月生活费、要骑驴找马 | 真正的门槛不是钱，是你敢不敢在简历空窗期里，不向任何人解释这段时间在干嘛 |
|  | 职场里，"会说话"到底有多重要 | 情商高 = 会拍马屁吗 | 要会说话、要圆滑、不得罪人 | "会说话"的本质不是讨好，是"让对方在 30 秒内知道你要什么、他要给什么"——它是效率，不是性格 |
|  | 35 岁危机，到底危在哪里 | 中年失业是注定的吗 | 要提前转型、要搞副业、要保持学习 | 35 岁的真正危机不是年龄，是你在一家公司待久了，把"岗位能力"误当成了"市场能力" |
|  | 加班到深夜，到底值不值 | 努力工作就是对的吗 | 年轻要拼、多付出才有回报 | 判断加班值不值，只看一件事：今天加的这 3 小时，是在长本事，还是只是在给昨天的低效买单 |

|  | 明明很累，休息的时候却总觉得自己在偷懒 | 为什么休息反而更焦虑 | 要自律、不能躺平、别人都在努力 | 你不是在休息，你是在"边休息边审判自己"——大脑一半在躺，一半在骂，比上班还累 |
|  | 想念一个不再联系的人，不一定要重新联系 | 放不下一个人该怎么办 | 要放下、要开始新感情、时间会治愈一切 | 想念不是为了重新联系，是承认"那个人真的来过"——你允许自己想，但不代表要回头，这两件事不矛盾 |
|  | 心情不好又说不出原因，可以暂时不解释 | 说不出的低落要不要紧 | 要找到原因、要倾诉、要调节情绪 | 情绪不是必须被解读的密码——有时候它就是下雨了，你不用问云为什么哭，撑伞走过去就行 |
|  | 和家人聊完天很疲惫，怎样给自己留一点缓冲 | 为什么和亲人说话比上班还累 | 有代沟、观念不合、要耐心 | 那不是沟通累，是你在那几个小时里一直在"扮演他们期待的那个你"——回家后的疲惫，是卸妆的疲惫 |
|  | 一次争执结束了，心里的那口气还没过去 | 为什么吵完架好久都缓不过来 | 要翻篇、别计较、大度一点 | 那口气不是"还在生气"，是你当时没说出口的那句话，在心里反复重播——它需要的不是原谅，是你自己听见自己 |

# 个人成长

| 是否使用 | 选题 | 核心问题 | 常见解释 | 切入角度 |
| --- | --- | --- | --- | --- |
|  | 一件事做得不好，先别急着否定自己这个人 | 怎么区分"事情没做好"和"我不行" | 要复盘、要改进、下次注意 | 事情没做好，只是这一次、这件事、这个方法出了问题——你习惯性地把它扩大成"我这个人不行"，这才是真正拖垮你的东西 |
|  | 被人指出问题以后，怎么把有用的意见留下来 | 被批评后怎么不内耗 | 有则改之无则加勉、不要玻璃心 | 先别忙着接受或反驳，把对方的话拆成两半——"事实部分"留下来改，"情绪和人身部分"直接扔掉，你会发现真正有用的其实只有 20% |
|  | 一个人去做以前不敢做的事：从小小的一次尝试开始 | 社恐/胆小怎么破 | 要勇敢、要迈出第一步、逼自己一把 | 不需要"勇敢"那么大的词——一个人去吃一顿饭、一个人看一场电影、一个人坐过一站地铁，这些小事积累起来，你会发现世界并没有你想象中那么多人在看你 |
|  | 总被手机打断的晚上，怎么留一点时间给自己 | 为什么一到晚上时间就没了 | 要自律、要卸载 App、要锁屏时间 | 不是手机偷走了你的晚上，是你自己愿意被它偷走——因为"做点什么"比"面对自己"容易，那些被手机填满的时间，其实是你在躲 |
|  | 越想把事情做好，越不敢让别人看见半成品 | 完美主义为什么让人不敢开始 | 要完成不要完美、先做出来再说 | 你怕的不是"做得不好被笑"，是怕别人看见那个"还在学、还不行"的你——但成年人的世界里，没有人是准备好了才上场的 |
|  | 学会一项新东西以后，才发现自己没想象中那么笨 | 为什么总觉得自己学不会新东西 | 年纪大了、脑子慢了、不是那块料 | 你不是笨，是太久没有"从不会到会"的体验了——那种生疏、那种慢、那种挫败，本来就是学习的前 30 个小时，不是你不行的证据 |

# 婚姻两性

| 是否使用 | 选题 | 核心问题 | 常见解释 | 切入角度 |
| --- | --- | --- | --- | --- |
|  | "你告诉我，我就做"：为什么这句话反而让伴侣更累？ | 为什么"我听你的"反而让人火大 | 他随和、他尊重我、他没主见 | "你说"翻译过来是"我不想负责，也不想动脑筋——如果搞砸了，是你选的"——这不是温柔，是把决策成本全推给了你 |
|  | 两个人都上班，为什么只有一个人下班后还在"值班"？ | 家务和情绪劳动怎么分 | 他忙、他不会、我做更快 | 真正累的不是洗碗拖地，是"记着家里还缺什么、孩子该打疫苗了、明天带什么饭"——这些看不见的"惦记"，大多还压在一个人身上 |
|  | 夫妻AA以后，谁来给请假带孩子的那个人"结账"？ | 婚姻里AA公平吗 | AA制独立、不占对方便宜、现代婚姻 | AA 只算了"看得见的账"，没算"谁牺牲了职业上升、谁半夜起来喂奶、谁在照顾双方父母"——这些隐形劳动，在 AA 的账本上是零 |
|  | 吵架后照常做饭、照常接娃，算和好了吗？ | 不吵架的婚姻就是好的吗 | 夫妻哪有不吵架的、日子还要过、别较真 | 饭是做了、娃是接了，但那个没说出口的"我错了"还悬在半空——你们不是和好了，是暂时把矛盾挂起了，下次还会接着吵 |
|  | 婚前说"我养你"，婚后买件衣服却要解释半天 | 为什么婚后花钱不再自由 | 要存钱、要顾家、要计划开支 | "我养你"当年是情话，婚后变成了"我的钱可以、你的钱要报备"——那句承诺最后变成了家庭里最不平等的一条规则 |
|  | "我都是为你好"：伴侣的关心，从哪一步变成了替你做主？ | 爱和控制怎么区分 | 他在乎你、他经验多、他也是好心 | 开头是"我建议你"，中间是"你应该"，最后变成"你必须听我的"——区别只在于：他有没有在你说"不"的时候，停下来 |

# 社会观察

| 是否使用 | 选题 | 核心问题 | 常见解释 | 切入角度 |
| --- | --- | --- | --- | --- |
|  | 朋友聚餐越来越贵，那个说"不去了"的人未必是不合群 | 为什么越来越多人不去聚餐 | 社恐、不合群、变孤僻了 | 一顿人均 300 的饭，可能是他一周的伙食费——他不是不想聚，是聚一次要犹豫三天，最后只能用"有事"当借口 |
|  | 微信里有很多人，生病时却不知道该找谁 | 为什么好友越多越孤独 | 成年人社交都这样、要习惯、要独立 | 几百个好友是"点赞关系"，不是"能借 2000 块的关系"——你手机里存的是通讯录，不是朋友 |
|  | "反正你在家"：没有上班的人，为什么成了全家的默认劳动力？ | 全职主妇/主夫为什么不被看见 | 在家又不累、做家务有什么辛苦 | "在家"被默认等于"有空"，"有空"被默认等于"随叫随到"——你一天的劳动在别人眼里是"反正你也没事干" |
|  | 家庭群里最沉默的人，可能正在做最多的事 | 为什么群里发言最少的人最累 | 他内向、他不爱说话、他不活跃 | 跑腿的是他、垫钱的是他、老人住院陪床的是他——但群里红包抢得最欢、说话最响的，往往什么都没做 |
|  | 一份婚礼请柬，为什么会让老朋友先算一遍生活费？ | 为什么参加婚礼成了负担 | 人情往来、份子钱、正常社交 | 一张请柬发过来，你第一反应不是"他要结婚了真好"，是"这个月工资还剩多少"——婚礼本该是祝福，现在变成了一场月度财务冲击 |
|  | 我们劝父母别买保健品，却很少问：谁在陪他们说话？ | 父母为什么总信骗子 | 老人贪小便宜、被洗脑了、不懂科学 | 卖保健品的小伙子每周打电话、记得她生日、上门陪她聊半小时——你一年回家两次，每次还在嫌弃她——她买的不是保健品，是有人陪她说话的那点时间 |
