# 选题文件地址
20_选题/选题

# 内容领域
情绪疗愈、个人成长、生活感悟

# 表格相关的列
序号、选题、内容领域、生成方式（）、文章链接、创作时间

# 列说明
序号：从数字1开始自增
生成方式：只有自动和手动，自动就是批量生成的，手动就是我指定的
文章链接：就是文章在这个知识库中的链接
创建时间：格式 YYYY-MM-dd

# 批量生成
批量生成选题的时候，需要填写序号、选题、内容领域、生成方式，其余列保持空就行
文章生成后，需要填写其余列

# 手动生成
如果创作的时候指定了选题，那么就需要将选题插入到已完成的选题和未完成之间，并填写相关内容：内容领域你根据情况自行填写，生成方式是手动
